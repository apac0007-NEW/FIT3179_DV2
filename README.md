# Community Festivals in Australia — FIT3179 submission bundle

The website files are at the root of this bundle: `index.html`, `css/`, `data/`, and `specs/`.

## Publish on GitHub Pages

1. Create a public GitHub repository for the assignment.
2. Upload the **contents** of this bundle (not a nested folder) to the repository root so `index.html` is at the top level.
3. In repository **Settings → Pages**, deploy from the main branch and root folder.
4. Open the published URL in a private/incognito browser window and confirm the page and all 15 charts load.
5. Add your own hand-drawn A4 sketch PDF to the public repository and submit both URLs plus the description document in Moodle.

## Important scope and interpretation notes

- Creative Australia’s Soundcheck dataset maps 535 music festivals in 2022–23 across all states and territories; it is festival-specific but does not represent all types of neighbourhood celebrations. The 2025 National Arts Participation Survey is used for the most recent national attendance and access indicators.

## Important before publishing

The state/territory GeoJSON in the supplied previous version did not include its original edition or licence. The site transparently notes this. Verify it against the ABS ASGS boundary source and record the exact edition/licence before publishing. All chart data and Vega-Lite specs are local; the visualisation libraries and web fonts load from CDNs.
